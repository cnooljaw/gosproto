# TypeScript 编码与维护规则

- `typescript/src/sproto.ts` 是唯一维护源码，JS由构建产生；使用方vendor副本通过同步工具更新。
- 保持已有公开API、wire、资源预算、结果独占和缓存上限，避免迁移夹带算法重写。
- 当前保留上游历史格式及 @ts-nocheck；不为格式统一大规模改写热路径。新增独立工具使用严格类型检查。
- Node Buffer 的分配、视图与复制语义必须明确；公开返回值不得引用后续调用会覆盖的scratch。
- 整数只接受已验证的JavaScript安全整数；不宣称BigInt、double、浏览器或引擎支持。
- 外部输入校验不因基准提速删除；错误后后续有效调用与已返回结果保持正常。
- 测试覆盖独立官方向量和失败行为；单纯自身roundtrip不能证明wire兼容。
- profile、诊断包装与正式计时分开；不把Node下的性能结果直接推广到浏览器引擎。
- 上游版权、提交来源及BSD-2-Clause许可证随源码和分发产物保留。
